# Layered Network Telemetry for Security Incident Triage: Hop-Level AS/Geo Path Context and Per-Layer Active Probing at a Remote Satellite-Connected Site

**Author:** MSc. Medardo Jairo Suntaxi Cocanguilla, C|EH  
**Version:** 1.0 – October 2026

Independent technical white paper on how hop-level path ownership (mtr-geo) and per-layer active probing (PiProbe)
separated network, application and reputation causes in two security-relevant cases at a remote satellite-connected site:
a provider latency alert, and an outbound mail block caused by infected clients and IP/netblock reputation.
